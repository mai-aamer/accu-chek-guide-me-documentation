# Documentation Plan

This plan describes how the Accu-Chek Guide Me documentation was scoped and organized before writing began.

## Product

The Accu-Chek Guide Me is a blood glucose meter. It uses test strips and connects to the mySugr app via Bluetooth. Its screen is easy to read.

## Target Audience

People with diabetes, caregivers, and first-time users of a blood glucose meter.

## Documentation Goal

To help users understand how to use the blood glucose meter correctly and safely.

## Scope

### In Scope

| Area | Covered In |
|---|---|
| What the product is and what it offers | [Product Overview](product-overview.md) |
| Preparing the meter and the test strip | [Getting Started](getting-started.md) |
| Performing a test, understanding results, using stored results | [User Guide](user-guide.md) |
| Safety information, warnings, and precautions | [Safety](safety.md) |
| Common problems and selected error codes | [Troubleshooting](troubleshooting.md), [Error Messages](error-messages.md) |
| Cleaning, storage, and device care | [Maintenance and Care](maintenance-and-care.md) |
| Technical specifications and product information | [Reference](reference.md) |
| Technical terms | [Glossary](glossary.md) |
| Documentation scope, audience, goals, and structure | Project Planning ([Documentation Plan](01-documentation-plan.md), [Information Architecture](02-information-architecture.md)) |

### Out of Scope

- Detailed cleaning and disinfecting procedures, and test strip specifications. Users are referred to the official user manual and the test strip package insert.
- A complete list of error codes. Only selected codes are covered.
- The step-by-step control test procedure. Users are referred to the official user manual.

## Deliverables and Tools

- **Deliverables:** user documentation pages, organized as described in [Information Architecture](02-information-architecture.md).
- **Tools:** Markdown for writing, GitHub for source files, and Confluence for publishing.
