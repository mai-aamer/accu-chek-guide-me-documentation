# Reference

This page summarizes the main technical specifications and product information for the Accu-Chek Guide Me meter, based on the [official user manual](https://www.accu-chek.com/document/accu-chek-guide-me-users-manual-english/download?inline).

## Technical Specifications

> [!NOTE]
> For blood volume, sample type, measuring time, measuring range, and test strip storage and operating conditions, see the test strip package insert.

| Specification | Value |
|---|---|
| Meter storage conditions | Temperature: -13 to 158 °F |
| Memory capacity | 720 blood glucose results and 30 control results, with time and date |
| Automatic off | 90 seconds after a test; 15 seconds after the test strip is removed |
| Power supply | Two 3-volt lithium batteries (coin cell type CR2032) |
| Display | LCD |
| Dimensions | 76 × 48 × 16 mm (L × W × H) |
| Weight | Approx. 43 g, with batteries |

## Product Information

| Item | Details |
|---|---|
| Meter name | Accu-Chek Guide Me |
| Compatible test strips | Accu-Chek Guide test strips |
| Connectivity | Bluetooth low energy, for connection to the mySugr app |
| Wired connection | USB micro-B connector |
| Radio frequency | Bluetooth low energy, 2.402 to 2.480 GHz, maximum transmitted power 0 dBm (1 mW) |
| Measurement units | mg/dL or mmol/L |
