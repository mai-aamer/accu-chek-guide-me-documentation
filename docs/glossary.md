# Glossary

This glossary explains the technical terms used in this documentation.

## Technical Terms and Definitions

| Term | Definition |
|---|---|
| Blood Glucose | The amount of glucose in the blood. |
| Blood Glucose Meter | A device that measures the level of glucose in the blood. |
| Blood Glucose Result | The blood glucose value shown on the meter display after a test. |
| Bluetooth | A wireless technology that lets the meter connect to compatible devices. |
| Control Solution | A solution used with a test strip to perform a control test. |
| [Control Test](troubleshooting.md#if-the-meter-is-dropped) | A test that checks whether the meter and the test strips are working correctly. |
| Lancet | A small sterile needle used with a lancing device to obtain a drop of blood. |
| [Lancing Device](user-guide.md#preparing-the-lancing-device) | A device that holds a lancet and is used to obtain a drop of blood for testing. |
| mg/dL and mmol/L | The two units in which the meter can display a blood glucose result. |
| mySugr App | The app that the meter connects to via Bluetooth. |
| [Penetration Depth](user-guide.md#setting-the-penetration-depth) | How deep the lancet pricks the skin. A higher number on the comfort dial means a deeper puncture. |
| Test Strip | A strip that is used with the meter to measure blood glucose. |
| [Use By Date](getting-started.md#preparing-the-test-strip) | The date on the test strip container after which the test strips must not be used. |
