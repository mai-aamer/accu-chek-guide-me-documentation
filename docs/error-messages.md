# Error Messages

> [!NOTE]
> This page covers selected error codes.

When something goes wrong during use, the meter shows an error message on the display. Find the code in the table below to see what it means, then follow the steps in What to Do. For other problems, see [Troubleshooting](troubleshooting.md).

## Error Codes

| Code | Meaning |
|---|---|
| `E-1` | The test strip may be damaged or inserted incorrectly. |
| `E-3` | The blood glucose result may be affected by an incorrect test procedure. |
| `E-4` | There may not be enough blood on the test strip for the test. |
| `E-6` | A problem occurred during the blood glucose test. |

## What to Do

> [!NOTE]
> - Follow the instructions shown on the meter display.
> - When required, repeat the test with a new test strip.
> - If the problem continues, check the user manual or contact Accu-Chek Customer Care.
