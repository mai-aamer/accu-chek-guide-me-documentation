# Troubleshooting

This page lists common problems you may have with the meter and how to solve them. For codes shown on the display, see [Error Messages](error-messages.md).

## Common Problems

| Problem | Solution |
|---|---|
| The meter does not turn on | Make sure the batteries are inserted correctly. Replace the batteries if needed. |
| The test does not start | Make sure the test strip is fully inserted. Use a new test strip if the current one is damaged or past its Use By date. |
| The blood glucose result does not match how you feel | Run a control test, then repeat the blood glucose test. If the result still does not match how you feel, follow your healthcare professional's instructions. |

## Solutions

### If the Meter Is Dropped

1. If a test strip was inserted, throw it away.
2. Run a control test with a new test strip.
3. Only then repeat the blood glucose test.
